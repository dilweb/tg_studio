# Коворкинг: общий план рефактора (v2, dev-среда)

Цель: CRM управляет продажей **времени 4 рабочих мест** независимым мастерам и сопутствующими продажами (расходники, уход). Главный клиент CRM — **мастер**.

## Ключевые решения (зафиксировано владельцем)

1. **Dev-среда, данные тестовые** — можно сносить и пересоздавать без миграций сохранения истории. Legacy-модули вычищаем по ходу рефактора (док 08 — облегчённый).
2. **100% предоплата за часы.** Бронь подтверждается только полной оплатой стоимости. **Понятия «долг» нет**: место либо полностью оплачено, либо бронь не состоялась.
3. **Отмена (базовое правило):** отмена за **≥ 24 часов до начала** брони — **100% возврат**; позже — удержание (базово 100%, точную политику доработаем позже, она параметризуется).
4. **Экраны:** владелец — **дашборд наблюдаемости на основной странице** + разделы; мастер — **календарь мест, тарифы (свои цены), баланс**.
5. **Апсейлы админов:** администратор фиксирует, что продал (уход клиенту / расходники мастеру), чтобы владельцу потом **доначислять** админа (док 05/06).
6. **4 рабочих места, у каждого — свой календарь** (отдельная лента событий по месту).
7. **Раздел «Настройка мест»** у владельца: динамическая ценовая политика — утро/вечер, будни/выходные, праздники/особые даты, скидки; цены меняются быстро, под рынок.
8. **Excel-отчёт по выручке** для бухгалтера (выгрузка .xlsx за период).
9. **AI-ассистент не делаем** — вычёркнут из плана.

## Доменная карта

```
Мастер (главный клиент CRM)
   │
   ├── смотрит календари 4 мест и бронирует место на интервал   [02]
   │       └── видит свою цену по тарифу до подтверждения       [03]
   ├── оплачивает 100% стоимости брони                          [04]
   └── видит баланс, историю, свои покупки                      [04][06]

Администратор
   ├── отмечает приход/уход по брони, оформляет продажи        [05]
   └── фиксирует апсейлы (что продал и кому) → база для доначислений [05][06]

Владелец
   ├── ОСНОВНАЯ СТРАНИЦА = дашборд: загрузка мест сегодня, выручка,
   │   активные брони, отмены/неявки, апсейлы админов, остатки склада [07]
   ├── «Настройка мест»: 4 места + цены (утро/вечер/праздники/скидки) [02][03]
   ├── управляет допуском мастеров и администраторов            [05]
   └── отчёты + Excel для бухгалтера                            [07]
```

## MVP

- 4 места, бронь мастером, защита от пересечений/двойных броней;
- цена из «Настройки мест» (утро/вечер/будни/выходные/праздники/скидки), показывается до подтверждения;
- 100% предоплата → подтверждённая бронь; не оплатил за срок hold — бронь истекла, место свободно;
- отмена ≥24ч — 100% возврат; позже — удержание по правилу;
- баланс мастера (пополнение/списание/возврат), вебхук с дедупом;
- админ: отметка начала/завершения, продажа с фиксацией апсейла (admin_id), доначисления владельцем;
- дашборд владельца на главной; Excel-отчёт по выручке.

**Вне MVP:** сложные отмены/переносы сверх базового правила, пакеты/подписки, бонусы, AI-ассистент, привлечение студией тату-клиентов.

## Глоссарий

- **Место (seat)** — один из 4 ресурсов студии; у каждого своё расписание/календарь и может быть своя цена.
- **Бронь** — мастер занимает место на [start, end). Подтверждается только 100% оплатой. Нет долгов.
- **Hold** — временное удержание места на период оплаты; истекает по таймауту.
- **Тарифное правило** — цена часа для места/всех мест в интервале (утро/вечер, будни/выходные, особая дата). Настраивается владельцем, применяется к новым броням.
- **Баланс мастера** — журнал: пополнение, списание за бронь/товар, возврат. Остаток вычисляется.
- **Апсейл** — продажа, оформленная администратором (уход клиенту, расходники мастеру); у апсейла есть автор-админ и сумма — база для доначисления.
