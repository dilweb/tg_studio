# 07. Дашборд владельца (основная страница) + отчёты + Excel — план работ

Владелец открывает CRM → сразу видит, что происходит в студии **сейчас и за период**. AI-ассистент не делаем.

## Дашборд (главная страница владельца)

Виджеты (данные — агрегаты из доков 02–06):

- **Сейчас**: кто из мастеров на месте (брони `начата`), кто должен прийти сегодня (следующие брони), свободно/занято по 4 местам на ближайшие часы;
- **Сегодня/неделя**: выручка (оплаченные брони + продажи), количество броней, отмены/неявки и удержания;
- **Загрузка мест**: % за период по каждому из 4 мест (и разбивка утро/вечер/выходные);
- **Апсейлы**: продажи по админам за период (суммы) — для доначислений;
- **Деньги**: поступления за период, неиспользованные балансы мастеров, возвраты;
- **Склад**: позиции ниже порога (тревога);
- **Исключения**: неявки, истёкшие hold'ы, брони вне покрытия.

## Отчёты (раздел «Отчёты»)

- **Выручка**: по броням (по местам, по дням, утро/вечер), по продажам, итого; период任意лый.
- **Загрузка**: доступные/п занятые место-часы, % по местам, блокировки.
- **Мастера**: новые, активные, выручка и часы по мастеру.
- **Деньги**: поступления, балансы, возвраты, удержания по отменам.
- **Апсейлы и доначисления**: по админам.

**Принципы:** выручка (признанная) ≠ поступления (cash flow) — считаются отдельно; все цифры — агрегаты фактов, без отдельных «отчётных» таблиц; периоды — по таймзоне студии.

## Excel для бухгалтера

- `GET /reports/revenue.xlsx?from=&to=` — файл .xlsx: лист «Выручка» (дата, тип операции — бронь места №N / продажа, мастер/покупатель, сумма, способ оплаты, внешний id платежа, ссылка на бронь/продажу), лист «Возвраты и удержания», лист «Продажи товаров» (с себестоимостью), итоги за период.
- Каждая строка связана с внешним платежом (id) — для сверки с банком и чеками.

## API (эскиз)

- `GET /dashboard` — все виджеты одним запросом (или набором лёгких).
- `GET /reports/usage|revenue|masters|money|upsells?from=&to=`.
- `GET /reports/revenue.xlsx?from=&to=` — выгрузка Excel.

## Задачи

1. Агрегирующие запросы + индексы под них.
2. Дашборд-эндпоинт и страница (главная для роли owner): виджеты, автообновление (polling, без websocket в MVP).
3. Страница отчётов с выбором периода и 5 вкладками.
4. Генерация .xlsx (библиотека openpyxl/xlsxwriter; без внешних сервисов).
5. Тесты: сверка дашборда/отчётов с фактами на фикстуре; Excel содержит все оплаченные операции периода и сходится с выручкой.

## Критерии готовности

- Владелец за 10 секунд видит загрузку 4 мест, выручку, апсейлы и тревоги.
- Бухгалтер получает .xlsx, который сходится с журналом платежей.
